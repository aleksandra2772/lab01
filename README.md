Лабораторная работа №1

Название: Анализ устройства современной информационной системы

Цель: Получить представление об устройстве современных информационных систем на примере реальных цифровых сервисов.

Вариант: 8, платформа GitHub

Краткое описание результата: В работе проанализирована платформа GitHub на примере пользовательского сценария «создание нового репозитория». Описаны страницы и элементы интерфейса, исследована клиентская часть с помощью DevTools, описаны серверная часть и API, построена архитектурная схема.
